# TrustForge — Recreated

A recreated version of the TrustForge GitHub repository authenticity interface based on the original project video.

## Features

- Dark neon TrustForge landing page
- GitHub username/profile URL validation
- Incorrect-user state matching the original visual direction
- Loading authenticity-assay animation
- Trust report with score cards
- Responsive layout
- Framer Motion transitions
- GitHub public API integration

## Run

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite.

## Notes

The trust-analysis values are intentionally frontend-generated demo scores. GitHub is used to validate that the public user exists and to read the public repository count.
